# ToDoListTGBot

This repository contains a Telegram bot built with Python and the Telebot library, designed to help users manage their to-do lists. The bot allows creating hierarchical lists, adding tasks (todos), and navigating through them via inline keyboards. It uses SQLite for data storage and includes basic logging functionality.

## Available Commands

- `/patchnotes`: Retrieves and displays the latest patch notes from a file.
- `/new_list`: Initiates the creation of a new main list by prompting the user for a name.
- `/my_list`: Displays all the user's main lists for selection and management.
